# Stripe Payment Module with 3D and SCA Secured Payments

# Accept payments from all Bank Cards Secured with 3D Secure, Strong Customer Authentication

**One package for all OpenCart 4 versions: 4.0.0.0 - 4.0.2.3 and 4.1.0.0 - 4.1.0.4.**

## How To Install
1) In your OpenCart admin panel go to Extensions > Installer
2) Upload the file `stripe.ocmod.zip`
3) Click the green install button of the uploaded extension, wait until it is finished
4) Go to Extensions > Extensions, choose Payments from the extension type
5) You will see the Stripe payment module there, click the Install button
6) After installing finished, click on the edit button, update the Stripe settings (environment, keys, order statuses)

Congratulations! Stripe Payment Module with 3D Secure Payment Support is now installed. You can now accept Credit/Debit cards payment on your site.

## Features
1. Easy to install and setup
2. Accept payments directly on your site
3. Support 3D Secure (3DS) and Strong Customer Authentication (SCA) Card Payments
4. Accept all Credit/Debit Card
5. Support Test & Live Mode
6. Multi Currency Support (including currencies without decimals like JPY)
7. Built on latest Stripe Official SDK
8. Fast, Secure & PCI Compliant
